gmail-yun

gmail-yun is a small personal tool used by a single individual to prepare Gmail draft messages (for example, job application emails with attached files) and to check that those drafts exist.

What the app does

  • Creates draft emails in the user's own Gmail account, with attachments.
  • Lists and deletes the drafts it created, and reads message headers when the user asks it to.

The app never sends email on its own and is not offered to the public. Only the account owner uses it.

Google user data

The app requests the Gmail scopes gmail.compose and gmail.readonly for the owner's own account. See the Privacy Policy for how that data is handled.
